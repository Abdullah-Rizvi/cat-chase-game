# 🐱 Cat Chase Game

A simple 2D retro-style game where you play as a cat trying to catch a bouncing ball before time runs out. Built with HTML, CSS and JavaScript (Canvas) as a personal practice project.

## 🎮 Play Online

**[Click here to play](https://abdullah-rizvi.github.io/cat-chase-game/)**

## 🕹️ How to Play

- **Move the cat:** Arrow keys or WASD (on phones and with a mouse, press and drag)
- **Start or restart:** Space, Enter, or tap the screen
- **Goal:** Catch the ball before the 30-second timer ends

## ✨ Features

- Retro pixel-art style with scanline effect
- Ball gets faster with every catch and tries to run away from the cat
- Each catch adds 1 point and 1.5 seconds to the timer
- High score saved in the browser
- Sound effects using the Web Audio API
- Works on desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Canvas API)

## 🚀 Run Locally

1. Download or clone this repository
2. Open `index.html` in any web browser
